# 二元路由留一任务族验证设计

## 研究问题

二元路由已经能在已见回放与 QASC 之间完全分流，但在一个消费开发任务族上错误开启。
本实验不再观察或调整消费开发集，而是在 7 个公开训练来源内部做 leave-one-family-out
验证，判断路由能否把“专家何时有益”迁移到训练时未见的来源。

## 固定实验

- 冻结同一个父模型和两阶段训练得到的专家；
- 由 `route=0` 与 `route=1` 的反事实总代价生成二元目标；
- 依次留出每个公开来源，留出来源的目标和特征只用于该折评测；
- 比较两个等计算量训练臂：
  - `row_weighted`：从其余来源的全部行均匀抽样；
  - `source_balanced`：每次更新从每个其余来源各抽一行；
- 每折每臂使用 `1801/1802/1803` 三个随机种子；
- 每次训练 128 次更新，推理阈值固定为 `0.5`；
- 评测准确率、平衡准确率、Brier、对数损失、目标与预测打开率，并与仅使用训练折
  打开率的常数预测比较。

路由输入仍只有空材料下的任务和候选表示，不包含来源、任务族、样本 ID 或答案。

## 预注册判定

任务族均衡训练只有同时满足以下条件，才值得进入下一轮完整路由训练：

1. 7 个留出来源 × 3 个种子全部完成且没有训练/留出泄漏；
2. 宏平均 Brier 比普通行均衡训练至少改善 `0.01`；
3. 宏平均 Brier 比各折训练打开率常数预测至少改善 `0.01`；
4. 宏平均平衡准确率至少为 `0.55`；
5. 7 个来源各自的三种子平均 Brier 均不劣于普通训练超过 `0.02`。

任一条件失败都只保留为机制证据，不训练新的候选发布端点，也不根据留出结果修改阈值。
