# 公开语义训练扩量：预先固定的实验方案

本轮推进模型能力，不继续添加新的损失项。上一轮每个方法只训练过 48 条 SNLI，
24 次更新；它能验证梯度实现，却不足以判断模型能否学会推断任务。

## 固定什么、改变什么

- 固定 EuroBERT-2.1B、32 层 rank-8 LoRA、独立候选评分、单视图、CE + 0.5 Brier。
- 从 `architecture-study-v1/D-independent` 的同一份公开训练权重热启动；新优化器。
- 每组训练 768 条 SNLI，另复习 128 条 CLINC、96 条 Schema、32 条 Bandit。
- 两个种子（42、43），各一轮，共各 128 次更新；改变样本顺序、候选顺序和 dropout。
- 训练结束取最后一次更新的权重，完整报告两组；不按测试挑冠军或早停。

这是“新增语义任务 + 旧任务复习”的训练方案评估。数据和更新预算都比上一轮多，
所以不能宣称它隔离出了数据量的因果效果，也不是新的 RL 算法对照。
固定常规概率目标是为了先检查语义学习；已实现的带噪目标和策略梯度仍保留。

## 数据与评测

仅使用已审核许可的公开混合数据 v2。保留来源、分组与官方训练/验证/测试角色；
选择规则由来源配额、标签平衡、固定 ID 顺序决定，不读取模型的预测或错误。

| 划分 | SNLI | 旧任务 | 合计 |
|---|---:|---:|---:|
| 训练 | 768 | 256 | 1,024 |
| 验证 | 96 | 96 | 192 |
| 测试 | 192 | 192 | 384 |

旧任务的验证和测试 ID 与架构实验相同。评测起点和两组最终权重时使用完全相同
的 ID；温度只在本轮验证集拟合。GoEmotions 整类任务仍只测试，不参加训练与校准。
训练后的训练集指标使用固定 128 条探针，避免重复评测所有训练行；这不减少训练量。

预先确定的主要指标是 SNLI 原始准确率和 NLL。辅助指标是旧任务保留情况、情绪
任务迁移、原始/校准概率质量、候选换序与重载一致性。保留标签混淆和逐条得失，
检查是否出现只预测单个标签的退化。

## 可以与不可以得出的结论

- 可以回答：这一预算下是否学会更多同分布推断样本、是否牺牲旧任务。
- 两个种子可暴露一次训练的偶然性，但不足以建立稳健的种子分布结论。
- SNLI 参与训练，测试提升不属于任务零样本；反复观察的情绪任务也不属于盲测。
- 基础预训练是否见过这些公开基准未知。
- 通用零样本目标还需要未用于开发的任务族、指令改写、多语言和困难候选评估。

## 实现

`scripts/run_semantic_scale_study.py` 先冻结配置、代码哈希、训练数据和起点权重，
再顺序执行起点评测、两次训练和结构审计。每条训练样本实际出现的次数会被复核。
`scripts/semantic_scale_report.py` 在完整结束后才生成报告和允许导出。
实验不上传任何数据或权重。

```bash
python scripts/run_semantic_scale_study.py --device mps
python scripts/semantic_scale_report.py
python scripts/export_study.py --kind semantic --study runs/semantic-scale-v1 \
  --output dist/semantic-scale-v1/adapters.tar.gz
```

需要一个新输出目录。先按数据说明重建公开语料并准备架构实验的固定起点；
初始版本要求起点文件哈希完全相同，跨硬件重训若产生不同哈希，需建立并记录新协议。
