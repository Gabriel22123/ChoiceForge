# 安全多专家路由留一任务族设计

## 目标

把完整目标分布安全 oracle 变成推理时可计算的路由器，并验证它是否能迁移到训练时完全
未出现的任务族。路由器不能读取来源、任务族、样本 ID、文本隐藏状态或标签。

## 输入和标签

- 固定路径：父模型、QASC、SNLI、PAWS-Wiki、CLINC 四个 canonical 专家。
- 每个请求提取 75 个候选顺序不变的行为信号：父模型候选数、full/null 熵、top 概率和
  margin；每个专家的 full/null 统计、与父模型的 JS 差异、top 翻转、残差幅度和
  full/null 残差差异。
- 标签由完整目标分布安全规则生成：先过滤会破坏父正确性、交叉熵、Brier 或期望上下文
  优势的专家，再选择 proper-loss 改善最大的安全路径；没有安全专家时标签为父路径。

## 留一任务族

六个来源逐一留出：QASC、SNLI、PAWS-Wiki、CLINC、Typed Decisions、JSON Schema。
每折只用其余来源的 `train` 行训练，使用留出来源的 `validation` 行评估。特征标准化、
类别权重和采样计划都只在训练折拟合。

- 三个路由种子：`42, 43, 44`。
- 两层 MLP：75 → 128 → 5。
- 来源均衡、batch size 64、固定 256 次更新。
- AdamW：学习率 `3e-4`、weight decay `0.01`、梯度裁剪 `1.0`。
- 交叉熵使用训练折内类别频率的平方根倒数权重，最大截断为 3；训练折缺失路径权重为 0。
- 推理时若最大路径概率低于 `0.5`，回退父路径；阈值不根据留出结果调整。

## 冻结门槛

三种子、六折汇总必须满足：

1. 无留出来源训练泄漏；
2. 平均准确率不低于父模型，平均完整目标交叉熵不高于父模型；
3. 每个来源平均准确率最多下降 1 个百分点，交叉熵最多恶化 0.02；
4. 被选路径相对完整目标安全规则的逐行违规率不超过 5%；
5. 平均 proper-loss 收益至少 `+0.01`；
6. 安全 oracle 路径匹配率至少 40%。

通过仅允许进入完整训练端点；失败则分析是特征不可分、置信回退不足或留出任务族标签先验
变化，不调留出阈值。
