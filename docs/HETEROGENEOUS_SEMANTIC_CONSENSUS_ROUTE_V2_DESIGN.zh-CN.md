# 六专家九来源语义一致性路由 V2 设计

## 问题

异构专家库的安全 oracle 已证明存在明显可选收益，但 oracle 使用真实标签，不能部署。此前五专家、七来源路由的安全精度只有 48%，没有形成可用端点。本实验只回答一个问题：新增 GSM8K 专家和 HellaSwag/GSM8K 元训练来源后，原有的三种子一致性路由能否在来源完全留出的条件下跨过既定安全门槛。

## 冻结方案

- 专家固定为 QASC、SNLI、PAWS-Wiki、CLINC、TruthfulQA 与 GSM8K 六个已训练端点；GSM8K 使用宽度 512，其余端点使用宽度 256。
- 来源固定为 qasc、snli、paws-wiki、clinc、typed-decisions、json-schema、truthfulqa、hellaswag 与 gsm8k。
- 每折完整留出一个来源；阈值校准的内层折也不得看到外层来源。
- 路由输入只含候选顺序不变的父模型/专家行为特征和冻结 2B 表征的固定随机投影摘要，不含来源名、样本 ID 或标签。
- 三个随机种子必须同时判断某专家安全且收益为正，才允许选择该专家。
- 沿用既有门槛，不因结果调整：总体准确率与交叉熵不退化，逐来源准确率最多下降 1 个百分点、交叉熵最多增加 0.02，违规率不高于 2%，安全精度至少 95%，专家覆盖至少 5%，平均 proper-loss 收益至少 0.005。

## 解释边界

九个验证来源都已用于研发，结果只能说明机制是否值得继续，不能作为最终零样本发布证据。SciFact 继续保持封存；只有本方案、代码、配置和权重全部冻结后，才允许按独立流程打开最终来源。
