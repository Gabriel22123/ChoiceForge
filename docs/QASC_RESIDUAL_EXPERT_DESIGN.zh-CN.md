# QASC 冻结父函数残差专家设计

## 问题

QASC 证明当前 2B decoder 能学习自然证据组合，但共享 LoRA 与共享读出头的更新会改变旧任务函数。降低更新幅度、回放蒸馏和空材料函数蒸馏都只减轻漂移，没有同时通过冻结门槛。

本轮不再给同一个共享参数集合增加约束。父模型的 LoRA 和读出头全部冻结，新增一个零初始化的候选残差头：

`最终分数 = 父模型分数 + 残差专家分数`

残差头的最后一层严格初始化为零，因此训练前对任意请求的输出与父模型完全一致。旧任务保留原请求和空材料请求的父分布蒸馏，新 QASC 样本提供金标与材料优势信号。只有残差头进入优化器。

## 冻结设置

- 父端点：`functional-retention-screen-v1/warm-functional-context`。
- 数据：与 QASC 双函数筛选完全相同的 512 条旧任务回放和 512 条半权重 QASC 训练样本。
- 训练：1 epoch、batch 2、累积 4、128 次更新；残差头宽度 256、学习率 `1e-4`。
- 父 LoRA 保留 autograd 和训练计算图以避开 MPS 对纯推理动态形状图的重复编译，但不进入任何优化器参数组；父编码器内所有 dropout 显式关闭，每次更新后立即清空父梯度。父读出头关闭梯度，候选前向块为 32。这只改变执行路径，不改变样本、目标或优化顺序；训练后的逐张量相等审计负责验证父函数没有被更新。
- 旧任务：原请求 KL 权重 1、空材料请求 KL 权重 1。
- 全部评测均已消费，只用于机制筛选；即使通过，也不能形成新零样本或发布结论。

## 必须同时满足的门槛

1. 训练前组合输出与父模型逐值相同。
2. 训练后父 LoRA 与父读出头每个张量逐值相同，残差参数发生非零变化。
3. 已见任务准确率下降不超过 0.5 个百分点，NLL 增量不超过 0.01。
4. 已消费开发集准确率下降不超过 0.5 个百分点，每个任务的材料优势下降不超过 0.005。
5. QASC 准确率至少提高 3 个百分点、NLL 至少下降 0.02、材料优势至少提高 0.02。
6. 候选换序、权重重载和候选 ID 重命名审计通过。

通过只表示该机制值得进入新的许可证审计任务族实验。任何多种子与发布判断仍需未读取的新来源。
