# SciFact 封存任务族最终评测设计

## 目的

用一次从未参与方法选择的公开任务族，检验冻结方案能否在不改变父模型硬选择的前提下，稳定改善概率质量。SciFact 属于科学主张验证，与已消费的意图分类、常识问答、自然语言推断、复述识别、数学题和结构化输出任务不同。

这项评测只检验“给定金标准依据后，判断依据支持还是反驳主张”，不检验文献检索能力。输入由主张、论文标题和标注的依据句组成；每个有标注文档形成一个二选一样本。

## 数据边界

- 官方来源：AllenAI SciFact，固定版本 `68b98a56d93e0f9da0d2aab4e6c3294699a0f72e`。
- 压缩包固定为 `3,115,079` 字节，SHA-256 为 `11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be`。
- 主张和证据标注使用 CC BY 4.0；摘要语料使用 ODC-By 1.0；代码使用 Apache 2.0。
- 只使用带 SUPPORT 或 CONTRADICT 标注的开发集主张/文档对。无证据样本合法跳过。
- 样本选择键只含 claim ID 和 document ID；候选顺序只含二者与候选语义 ID，均不读取标签。
- 按回答无关的哈希排序后最多取 256 行，至少需要 50 行。
- 原始压缩包、原始文本、转换后的文本与特征缓存均不进入发布包；公开仓库只保留来源、许可证、校验和、协议和聚合结果。

## 开封前冻结内容

1. 三组完整来源训练的专家组合权重及文件校验和。
2. 六个冻结专家、父模型、特征提取程序和所有源码校验和。
3. 固定组合步长：`0.125, 0.25, 0.5, 0.75, 1.0`。
4. 每行选择保持父模型 argmax 的最大步长；全上下文和无上下文路径使用同一步长。
5. 三个训练种子：42、43、44。
6. 下列通过门槛。开封后不调参数、不改门槛、不另选样本。

## 预注册门槛

每个种子都必须满足：

- 硬选择保持率 100%，因此准确率差严格为 0。
- 平均交叉熵差不大于 0。
- 平均 Brier 差不大于 0。
- proper-loss 收益至少 0.005，其中 `proper = 交叉熵 + 0.5 × Brier`。
- 上下文优势差至少 -0.01。
- 平均组合步长至少 0.05，排除完全退回父模型的空结果。
- 每行严格 JSON 输出契约通过率 100%。输出必须只含选择、候选概率、人工复核标记、分数语义和校准状态；人工复核标记恒为 true。
- 候选顺序等变性通过率 100%。

任何门槛失败都保留为负结果，不使用 SciFact 标签修改方法、阈值或权重，也不再开启另一个“最终”任务族替代它。

## 解释限制

决策稳定投影保证的是硬选择不会变差，不保证逐样本概率都改善。若聚合概率指标通过，它支持的是冻结专家组合在一个新任务族上的校准收益；它不能证明任意任务都提升。当前产物仍是父模型加六个专家和一个很小的组合策略，尚未蒸馏为单一适配器。
