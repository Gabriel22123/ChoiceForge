# QASC 共享空材料路由设计

软一致性仍允许完整与空材料视图产生不同门值。本轮改成结构上的严格共享：路由器只读取去材料后的任务与候选表示，得到一个请求级门值；同一个门同时缩放完整请求残差和空材料残差。

\[
g=Router(h_{null}),\quad z_{full}=z^p_{full}+gR(h_{full}),\quad z_{null}=z^p_{null}+gR(h_{null})
\]

因此材料差值只来自父函数与专家残差对材料的响应，不再包含路由变化。专家训练、21 点反事实目标、路由 MSE、128+128 次更新、数据和门槛全部保持不变。该结构会增加一次空材料路由特征计算；若机制通过，实时集成阶段必须测量这一额外成本。

所有评测任务均已消费。通过只允许进入实时模型集成、性能、候选换序/ID 重命名、保存重载和严格 JSON 输出审计。
