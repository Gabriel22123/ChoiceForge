# 可执行结果反馈：RLCD 原理解构与改进实验

## 研究问题

Typed Decisions 实验的教师概率可以直接求导，因此策略梯度失败并不能回答
RLCD 在真实结果反馈上的价值。本实验换成不可微的程序执行结果：模型从多个候选
程序中选一个，环境运行公开测试，只返回所选程序通过了多少条测试。

实验只回答三个有限问题：

1. 只观察所选动作结果时，策略梯度能否学到更高的执行通过率；
2. 在动作、结果和查询次数完全相同的前提下，奖励模型加双重稳健修正能否比
   朴素策略梯度更稳定；
3. 两种有限反馈方法距离“看到全部候选结果”的上界还有多远。

这不是生成代码实验，也不把 MBPP 上的有效性外推成一切决策任务的通用能力。

## 公开数据与隔离边界

- 数据：Google Research 的 Mostly Basic Python Problems，固定到提交
  `f46ca8374b4cddef97ca4208ad986049d74d296a`，数据许可 CC-BY-4.0。
- 开发阶段只执行官方训练 ID 601–974 和验证 ID 511–600。
- 官方测试 ID 11–510 不生成候选、不执行测试，直到方法、超参数和全部端点锁定。
- ID 1–10 的提示样例始终排除。
- 最终模型仍需要新的任务族盲测；MBPP 官方测试与训练同属代码任务，不能单独证明
  跨任务零样本泛化。

每题保留标准答案程序，并生成最多 7 个确定性的单点 AST 变异。标准答案与变异都
经过 `ast.unparse`，避免格式直接暴露身份。候选选取和展示顺序只由源码与 task ID
决定，不读取执行结果。参考程序未通过全部测试、没有可支持变异或所有候选奖励相同
的题会被排除。

结果母集生成后再应用 decoder 已有的 768-token 请求级准入门。该门同时检查整组
候选语义和每条独立候选路径；超限题在任何训练臂建立前统一排除。本次固定筛选集为
203 个训练题和 45 个验证题。

奖励为候选通过测试的比例 `r(a) ∈ [0,1]`。完整奖励表只用于数据审计、全信息上界和
最终评价；有限反馈训练函数只接收被记录动作、该动作奖励和行为概率。

## 执行约束

候选和每条测试在临时目录中的独立 Python 进程执行。入口在
`src/decision_model/code_outcomes.py`：

- 执行前解析 AST，只允许审查过的标准库导入；
- 拒绝文件、网络、进程、动态执行、反射和双下划线访问；
- 使用隔离解释器、最小环境变量、关闭标准输入、墙钟超时；
- Linux 工作器额外限制 CPU、地址空间、文件大小、文件描述符和进程数；
- macOS 对不能在 `preexec` 降低的资源项显式跳过，仍保留静态过滤、临时目录和超时。

这是面向固定公开数据的多层防护，不宣称 AST 过滤能构成通用 Python 安全沙箱。

## 四个训练臂

所有臂使用相同的 MiniCPM5 decoder 候选特征、初始策略头、训练行顺序、候选顺序、
更新次数和随机种子。第一阶段冻结 2B 表示，只训练小头；任何方法只有通过三种子
规则，才进入 LoRA 验证。

### H：硬胜者监督

把最高奖励候选当成单一标签做交叉熵。它会丢掉部分通过和并列最优信息，但代表最常见
的分类训练方式。它使用了完整奖励表，不属于有限反馈对照。

### O：全信息直接效用上界

策略 `πθ(a|x)` 的损失为：

`L_O = -Σ_a πθ(a|x) r(a)`

它读取每个候选的奖励，是低方差上界，不是部署时可获得的监督。

### R：有限反馈 IPS + 留一基线

先冻结初始策略 `π0`，定义有完全支持的行为策略：

`μ(a|x) = 0.8 π0(a|x) + 0.2 / |A|`

每个训练样本和每轮固定记录 8 个动作，只查询这些动作的奖励。R 与 D 共用同一份
动作、奖励和 propensity 日志。R 使用逆倾向权重和独立留一奖励基线：

`g_R = -(πθ(a)/μ(a)) stopgrad · (r(a)-b_LOO) · ∇ log πθ(a)`

留一基线不读取当前动作的结果，因此不改变期望梯度。实现不裁剪重要性权重；裁剪
会引入偏差，只能作为预先声明的稳定性消融。

### D：有限反馈双重稳健修正

D 增加一个独立的候选奖励头 `qφ(x,a)∈[0,1]`。奖励头只用同一日志中被选动作的
奖励做均方误差训练。策略目标为：

`L_D = -Σ_a πθ(a) stopgrad(qφ(a))`

`      - mean[(πθ(a_k)/μ(a_k)) (r(a_k)-stopgrad(qφ(a_k)))]`

第一项利用奖励头给出所有候选的低方差方向，第二项用真实结果修正奖励头误差。对任意
固定 `qφ`，该策略梯度的期望都等于全信息目标梯度。单元测试已通过对所有动作的穷举
验证。D 的优势若成立，来自更好的控制变量，而不是偷看未选择候选的结果。

## 固定训练协议

- 表示端点：已完成 decoder 架构协议的 seed 42、43、44 三个端点全部运行，不事后挑种子；
- 每个端点的策略头初值保持不变，D 的奖励头以零权重初始化，对应初始预测 0.5；
- 每臂固定 20 个 epoch、batch size 16、AdamW、学习率 `3e-4`，不按验证集早停；
- R/D 每行每 epoch 记录 8 次行为动作；行为日志在训练前写入并哈希，两臂逐字节共用；
- 训练期间不解析官方测试段；所有最终权重和配置哈希写完后才能执行一次测试；
- 第一阶段只比较小头。通过规则的方法另开协议验证 LoRA，不能把小头结果直接写成
  2B 模型已经完成训练。

## 指标与晋级规则

验证集主指标是决策遗憾：

`regret = max_a r(a) - r(argmax_a πθ(a))`

同时报告策略期望奖励 `Σπr`、最优集合命中率、选择满分候选的比例、重要性权重分布、
奖励头 MSE 和三种子均值/最差值。并列最高奖励中的任意候选都算最优命中，避免把
等价程序错误地算错。

D 相对 R 只有同时满足以下条件才晋级：

1. 三种子平均 regret 更低；
2. 至少 2/3 种子的 regret 更低，任一种子退化不超过 0.02；
3. 三种子平均策略期望奖励不下降；
4. 无日志哈希、行为概率、候选对齐或未选择奖励访问违规。

O/H 只帮助解释信息上界和硬标签损失，不参与 D 对 R 的同信息量结论。若 D 未通过，
保留负结果；不得改阈值、挑单种子或直接打开官方测试寻找更好结论。

## 本实验的独立边界

本实验不依赖任何外部实现的未公开训练细节，而是把“结果反馈、梯度估计、控制变量、
校准与跨任务证据”拆成可独立验证的部分。所有训练臂看到的信息、动作日志和评价边界
都在本仓库中明确记录，便于复现和审查。

真正的项目亮点应是：**从结果反馈的数学条件出发，公开每种方法能看到的信息，验证
估计量，再用同动作日志比较朴素与改进方法。** 如果改进无效，同样是可复现结论。
