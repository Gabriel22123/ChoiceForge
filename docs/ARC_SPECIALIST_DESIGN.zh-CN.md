# ARC 独立专家训练设计

## 要回答的问题

现有 QASC 专家在 ARC 上的效用接近零，说明一个任务专用专家不能直接当作通用科学专家。
本实验换一个问题：使用 ARC 官方训练拆分，能否在同一个冻结 2B 表示和冻结父决策头上，
训练出一个对 ARC-Challenge 与 ARC-Easy 都稳定有正效用的独立残差专家？

本实验不训练路由，也不把 ARC 结果当作新鲜发布证据。固定验证集此前已被消费，它只用于
判断“公开任务族专家能否独立成立”这一机制问题。

## 数据边界

- 数据集：AI2 ARC，固定 Hugging Face revision
  `210d026faf9955653af8916fad021475a3f00453`。
- 许可证：`CC-BY-SA-4.0`。
- 训练：ARC-Challenge 与 ARC-Easy 各 1,024 行，共 2,048 行。
- 验证：既有固定 ARC 验证集 384 行，每个子族 192 行。
- 训练选取键、候选顺序和长度准入均不读取 `answerKey`。
- 源答案字母不会进入模型；候选被确定性重排并改为本地候选 ID。
- 训练与验证的语义输入哈希交集必须为 0；跨来源重复输入从训练候选中剔除。
- 原始和转换后的 ARC 行留在 Git 忽略目录；仓库只保留下载方式、固定版本、许可证、
  文件哈希和汇总证据。
- `python scripts/prepare_arc_specialist_data.py --download-only` 只下载清单中的固定文件；
  去掉 `--download-only` 后执行本地转换和重合检查。

## 模型与训练

- 父模型：当前固定 MiniCPM5-2B 决策父模型。
- 冻结项：2B decoder 表示、父决策头以及所有父参数。
- 可训练项：`LayerNorm → Linear(2048,256) → GELU → Linear(256,1)` 残差头。
- 初始化：末层严格置零，所以训练前组合函数与父模型逐位相同。
- 输入：每个候选的独立最终 token 表示；不输入来源名、任务族、样本 ID 或答案字母。
- 随机种子：`42, 43, 44`。
- 每个种子固定训练 1 个 epoch；batch size 32；共 64 次更新。
- AdamW：学习率 `3e-4`、weight decay `0.01`、梯度裁剪 `1.0`。
- 训练目标：交叉熵 + `0.5 × Brier` + `0.25 × context-margin`；context margin 为
  `0.05`。完整上下文和去上下文特征均由同一冻结父模型一次性缓存。
- 不做基于验证集的早停、阈值选择、学习率搜索或种子筛选。

## 冻结判定门槛

三个种子必须同时满足：

1. 训练前相对父模型的最大 logit 差为 0；
2. 合并平均反事实效用至少 `+0.02`；
3. ARC-Challenge 和 ARC-Easy 各自平均反事实效用至少 `+0.01`；
4. 合并准确率相对父模型至少提高 `1` 个百分点；
5. 合并 NLL 至少下降 `0.02`；
6. 两个子族各自 NLL 都不得恶化。

反事实效用使用与此前路由研究一致的二元成本：父路径为 gate 0、完整专家路径为 gate 1，
成本由 NLL、Brier 和上下文优势组成。只有所有种子、所有子族通过，ARC 才计为一个
“已消费但独立成立”的正效用专家族。即使通过，恢复路由训练前仍需至少再获得两个来源
独立的正效用公开专家族。
