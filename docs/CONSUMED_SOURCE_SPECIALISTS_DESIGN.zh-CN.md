# 既有公开任务族独立专家筛选设计

## 背景

此前路由数据只有 QASC 一个正效用任务族，因为同一个 QASC 专家被应用到其他来源时均为
负效用。这不能证明其他任务族没有可学习专家，只能证明 QASC 专家不能跨任务直接复用。

本筛选为五个已经消费的公开任务族分别训练独立残差专家，验证“先有多个专用专家，再学
路由”的前提是否成立。所有特征和验证集都已在早期实验中使用，因此结果只属于机制证据。

## 任务族与拆分

| 任务族 | 训练行 | 固定验证行 |
|---|---:|---:|
| SNLI | 96 | 96 |
| PAWS-Wiki | 96 | 96 |
| Typed Decisions | 96 | 320 |
| CLINC | 96 | 42 |
| JSON Schema | 96 | 42 |

Bandit 只有 32 个训练行和 12 个验证行，本轮不纳入正式多种子结论。每个专家只读取自己的
训练来源，不读取来源名、任务族、样本 ID 或验证标签。训练与验证仍使用此前固定的公开数据、
许可证和冻结 2B 特征缓存。

## 统一训练协议

- 冻结 MiniCPM5-2B 表示和父决策头，只训练宽度 256 的零初始化残差头。
- 随机种子：`42, 43, 44`。
- 每个来源固定训练 16 epoch；每个 epoch 的样本顺序和候选顺序独立确定性打乱。
- batch size 32，每个种子共 48 次更新。
- AdamW：学习率 `3e-4`、weight decay `0.01`、梯度裁剪 `1.0`。
- 目标：交叉熵 + `0.5 × Brier` + `0.25 × context-margin`，margin 为 `0.05`。
- 不做验证集早停、超参数搜索、种子筛选或事后阈值选择。

## 单个任务族通过门槛

三个种子必须同时满足：

1. 训练前与父模型的最大 logit 差为 0；
2. 验证平均反事实效用至少 `+0.01`；
3. 验证准确率不低于父模型；
4. 验证 NLL 至少下降 `0.005`。

只有全部条件通过，该来源才计为一个“已消费的正效用专家族”。恢复路由研究至少需要三个
来源独立的正效用专家族，并且后续路由协议仍要使用留一任务族验证，不能用这些验证行调阈值。
