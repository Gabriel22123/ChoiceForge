# QASC 二元反事实路由设计

## 问题

连续路由即使给旧任务很小的门值，也会改变每个候选的分数。此前共享路由已经消除了
完整/空材料两条路径使用不同门值的问题，但仍在消费开发集上改变了少量硬决策。

## 机制

本筛选把路由改成二元选择：

- `route=0`：逐位返回冻结父模型分数；
- `route=1`：返回父模型分数加完整冻结专家残差；
- 路由只读取空材料下的任务和候选表示；
- 完整与空材料路径共享同一个二元选择；
- 训练目标只比较 `route=0` 和 `route=1` 的反事实总代价；总代价继续包含正确答案的
  proper loss、已有父教师 KL、材料优势，以及有父教师回放行上的父首选变化成本；
- 两种行为代价相同时固定选择父模型；
- 路由器用二元交叉熵学习，推理阈值固定为 `0.5`。

目标生成与推理路由都不使用来源、任务族、样本 ID 或答案字段。答案只用于离线生成训练
目标，角色与普通监督标签相同。

## 预注册判定

沿用上一轮的全部保持和 QASC 门槛，并新增：

1. 关闭路由的输出必须与父模型逐位相同；
2. 完整/空材料路由必须逐样本一致；
3. QASC 训练行的打开率至少比回放训练行高 `0.05`；
4. 任一门槛失败都不进入实时集成。

本轮仍是单种子、冻结表示、全部评测任务已消费的机制筛选。固定 `0.5` 是二元概率的
语义边界，不根据消费开发结果选择；运行后不调整阈值或损失权重。
