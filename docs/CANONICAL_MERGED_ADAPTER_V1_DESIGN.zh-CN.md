# 单文件合并适配器设计

## 目标

把已经通过 SciFact 封存评测的“父模型 + 六个冻结专家 + 组合权重”变成一个便于分发和调用的适配器文件。这里不再学习参数，也不使用任何标签选择结构或系数；只做可证明的代数重写。

## 固定选择

- 三个完整来源组合种子为 42、43、44。
- 规范端点固定为其中编号最小的已注册种子 42。该规则与任务结果和指标无关。
- 种子 42 已独立通过所有 SciFact 预注册门槛。
- 父路径和六个专家路径的权重和为 1，因此组合 logits 可写成 `父 logits + Σ(专家权重 × 专家残差)`；父路径权重不需要进入残差文件。

## 精确合并

每个专家残差是：

`LayerNorm(affine) → Linear → GELU → Linear(1)`。

不同专家的 LayerNorm 使用相同的归一化公式，只是 affine 参数不同。将每个 LayerNorm 的缩放和平移折叠到其第一层 Linear 后，可以：

1. 共享一个不带 affine 的 LayerNorm；
2. 纵向拼接六个第一层 Linear；
3. 保持逐块 GELU；
4. 横向拼接并按组合权重缩放最后一层。

最终宽度为 1792，输出严格等于六个专家残差的加权和，仅受浮点运算顺序影响。专家 router 不参与已验证组合，也不进入合并文件。

## 验证门槛

- 完整验证已消费的九个来源，以及封存后已消费的 SciFact。
- 全上下文和无上下文残差最大绝对差均不超过 `2e-5`。
- 每行决策稳定投影选择的步长与硬选择完全一致。
- 每行公开输出契约通过。
- 合并前后文件、配置、数据与缓存均做 SHA-256 完整性校验。
- 任何一项失败都不生成可发布适配器结论。

## 发布边界

适配器权重与模型元数据可作为公开发布资产。训练缓存、SciFact 原文和转换文本不进入仓库或发布包。该适配器仍依赖同一冻结 2B 父模型来产生候选特征与父 logits。
