# 语义增强分解式安全路由留一任务族设计

## 唯一机制变化

分解式安全路由 v1 只使用 75 个概率行为摘要，在 Typed Decisions 上无法识别新的软分布
监督结构。本实验保持它的安全标签、内层留一来源校准、优化预算和全部通过门槛不变，只
增加来自冻结 2B 主干的候选顺序不变语义摘要。

## 语义特征

- 对每个候选的 full 与 null 最终 token 2048 维冻结表示，使用种子 1701 的固定高斯矩阵
  投影到 64 维；投影矩阵不训练，也不接触标签或来源。
- 分别计算 full/null 投影候选集合的逐维均值和总体标准差，共 256 维；这些统计对候选
  排列严格不变。
- 与原 75 个行为特征拼接为 331 维。每个外层折的标准化仍只拟合训练来源。
- 路由不读取来源名、任务族、样本 ID、原始文本或标签；语义来自推理时已经计算的冻结
  候选表示。

## 训练和校准

六个来源逐一外层留出，每折使用三个种子 `42, 43, 44`。每个外层折内部逐一留出训练
来源，为四个独立专家安全头生成跨来源概率；门槛仍取不安全样本最高概率加 `1e-4`，
且不低于 0.5。收益头只负责在已放行专家中排序。内层 128 次更新，最终 256 次更新，
其余参数与分解式 v1 完全一致。

## 冻结门槛

沿用 v1：合并准确率与交叉熵不退化；每来源准确率最多下降 1 个百分点、交叉熵最多恶化
0.02；逐项违规率不超过 2%；已选专家安全精度至少 95%；专家选择率至少 5%；平均
proper-loss 收益至少 `+0.005`。外层结果不用于修改投影宽度、阈值或门槛。
