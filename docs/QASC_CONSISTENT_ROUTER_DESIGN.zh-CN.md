# QASC 成对一致反事实路由设计

反事实收益路由已通过 11/12 门槛。唯一失败来自同一请求的完整视图和空材料视图得到不同门值，使“材料变化”同时改变了专家调用强度。

本轮只改路由回归损失。在原有完整/空材料目标均方误差之外，增加权重 1.0 的成对门一致性：

\[
L = \tfrac12[(g_{full}-g^*)^2+(g_{null}-g^*)^2] + (g_{full}-g_{null})^2
\]

专家训练、反事实 21 点网格、数据、两阶段各 128 次更新、学习率、教师约束、评测集和全部行为门槛保持不变。该约束不使用评测标签；它表达的是接口不变量：删除材料可以改变候选证据分数，但不应把同一个任务路由到不同专家。

通过仍只允许实时模型集成、候选换序/ID 重命名、保存重载与严格 JSON 输出审计。本轮任务全部已消费，不形成新的零样本或发布证据。
