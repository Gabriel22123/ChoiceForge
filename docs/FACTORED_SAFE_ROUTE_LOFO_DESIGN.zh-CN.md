# 分解式安全路由留一任务族设计

## 假设

直接把父路径与四个专家压成五分类，会把“安全约束”和“收益排序”混成一个类别误差。
本实验改为先为每个专家独立判断是否满足完整目标分布安全约束，再只在通过安全门槛的
专家中比较 proper-loss 收益。没有专家通过时回退父路径。

## 模型与输入

- 固定父模型和 QASC、SNLI、PAWS-Wiki、CLINC 四个 canonical 专家。
- 输入仍为 75 个候选顺序不变行为特征，不含来源、任务族、文本隐藏状态、样本 ID 或标签。
- 一个共享 MLP 产生四个独立安全 logit 和四个收益回归值。安全标签分别表示该专家是否
  同时保持父正确性、完整分布交叉熵、Brier、期望上下文优势并产生正 proper-loss 收益。
- 收益头回归每个专家相对父路径的 proper-loss 改善；推理时只对安全头放行的专家排序。

## 外层留一任务族

六个来源逐一完全留出。每个外层折只用其余来源的 `train` 行训练，使用留出来源的
`validation` 行评估。三种子固定为 `42, 43, 44`。

## 训练折内安全校准

每个外层折内部，再逐一留出一个训练来源：模型仅在其余训练来源拟合，并为内层留出来源
产生安全概率。每个专家的门槛取所有内层留出预测中“不安全样本的最高概率 + 1e-4”，
且不低于 0.5、不高于 1.0。这使门槛在训练来源的跨来源预测上保持零经验假放行；外层
留出数据不参与标准化、类别权重、收益缩放、模型拟合或门槛选择。

最终模型在整个外层训练折重训。安全头使用每个专家训练折内平方根倒数正类权重，收益头
使用训练折均值和标准差归一化后的 Smooth L1。共享层宽度 128，batch size 64；内层
校准模型固定 128 次更新，最终模型固定 256 次更新；AdamW 学习率 `3e-4`、weight
decay `0.01`、梯度裁剪 `1.0`。

## 冻结门槛

1. 六折三种子完整，且外层留出来源不进入训练或校准；
2. 合并准确率与交叉熵不退化；每个来源平均准确率最多下降 1 个百分点、交叉熵最多恶化 0.02；
3. 全部行中的不安全专家放行率不超过 2%，已选择专家中的安全精度至少 95%；
4. 专家选择率至少 5%，避免通过永远回退父路径得到空结论；
5. 平均 proper-loss 收益至少 `+0.005`。

门槛冻结后不按外层结果调整。通过只允许进入已消费数据上的完整端点训练，不能形成发布
性能声明。
