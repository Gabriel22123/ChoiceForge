# 约束 margin 路由留一任务族设计

## 假设

一个二元“安全/不安全”标签仍会把不同失败原因混在一起。该实验显式预测每个专家相对父
路径的五个量：父正确性破坏风险、交叉熵差、Brier 差、上下文优势退化量和 proper-loss
收益。专家只有在每个约束的保守界都通过时才可参与收益排序。

## 训练与预测

- 一个共享 128 宽 MLP，输出每个专家的正确性破坏 logit，以及四个连续 margin。
- 正确性头使用二元交叉熵；连续头对训练折标准化后的 margin 使用 Smooth L1。
- 仍使用 75 个候选顺序不变行为特征，不读取来源、文本隐藏状态、标签或样本 ID。
- 六个外层任务族逐一完全留出；每个外层折内再逐一留出训练来源产生跨来源校准预测。
- 三个随机种子 `42, 43, 44`；内层 128 次更新，最终 256 次更新；其余优化参数与分解式
  路由 v1 相同。

## 训练折内保守界

- 正确性破坏概率门槛取内层留出中违规样本预测概率的最小值减 `1e-4`；预测风险必须更低。
- 三个约束差值使用内层留出预测残差的 99% 分位上界；`预测值 + 上界 <= 0` 才通过。
- proper-loss 收益使用 99% 分位下界；`预测收益 - 误差界 > 0` 才通过并用于排序。
- 行为支持度取标准化特征最大绝对值，必须不超过内层留出距离的 99% 分位数。

所有标准化、误差界、风险阈值和支持度阈值只使用外层训练来源。外层留出行只评估一次，
不用于调参。

## 冻结门槛

1. 合并准确率和交叉熵不退化，每个来源的准确率最多下降 1 个百分点、交叉熵最多恶化 0.02；
2. 全部行的逐项违规率不超过 1%，已选专家安全精度至少 95%；
3. 专家选择率至少 2%，避免空回退；
4. 平均 proper-loss 收益至少 `+0.002`；
5. 所有外层和内层拆分无留出来源泄漏。

该设计检验约束分解与保守残差界是否能提供可用的跨任务族安全精度，不把通过解释成正式
统计覆盖保证。
