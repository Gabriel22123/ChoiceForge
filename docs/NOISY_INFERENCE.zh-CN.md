# 补充观察：无噪声概率与平均带噪概率

这是在三组训练完成后增加的 CPU 概率诊断。主实验仍使用无噪声推理，不据此重新挑选权重或拟合温度。

从保存的校准概率按 `T × log(p)` 恢复分数（差一个无关常数），先核对恢复后的原始 NLL 与准确率，再加入标准差 0.4 的高斯噪声，对 softmax 概率求平均。
每条请求、每个种子使用 8,192 次采样；两次独立种子用于观察采样波动，各模型采用同一噪声序列。以下都是未加温度后处理的概率。
