# QASC 反事实收益路由筛选设计

## 核心改动

自由路由阶段把所有请求的门推到约 1，因为全局平均 gold loss 更偏好已经学会 QASC 的专家；教师约束不足以告诉路由器“哪一条请求该开”。本轮为每条训练请求构造行为目标：固定父函数和专家，在门值 `0, 0.05, …, 1` 上逐点计算同一个组合损失：

- gold 交叉熵 + 0.5 Brier；
- 旧回放的完整上下文教师 KL；
- 旧回放的空上下文教师 KL；
- 完整上下文相对空上下文的材料优势约束。

选择成本最低的最小门值，作为该请求的反事实最优门。路由器同时从完整表示和空上下文表示回归同一个目标，使是否调用专家与材料是否被删除解耦。目标来自两个可执行函数的逐行收益，不使用 source、family、ID 或任务二分类标签。

## 固定流程

1. 按两阶段实验的相同计划重新训练专家，路由保持初始值不变。
2. 在 1,024 条训练行上生成 21 点反事实门目标并固定文件哈希。
3. 冻结父函数和专家，路由器用完整/空上下文门均方误差训练一轮，共 128 次更新。
4. 用上一轮完全相同的已消费评测和门槛判定。

结构、优化器、学习率、训练权重及九项行为门槛保持不变；另要求初始函数完全相等、两个阶段参数隔离、目标覆盖完整、目标不读取来源字段。通过仍只允许实时集成和输出契约审计。
