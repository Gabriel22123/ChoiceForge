# QASC 父决策稳定共享路由设计

共享空材料门通过了全部条件差门槛，但三个消费开发样本越过父模型 argmax 边界。现有反事实目标用教师 KL 保持概率分布，没有直接表达“旧函数首选不应改变”。

本轮在教师存在的回放训练行上，为每个候选门值增加固定硬成本：若完整分支或空材料分支的首选候选与父函数不同，每个分支加 1.0。QASC 行没有父教师，不施加该成本。目标仍由行为计算，source、family 和 ID 不参与。

路由仍只读取空材料任务/候选视图，同一个门用于完整和空材料残差。专家、网格、更新次数、优化器、数据和评测门槛均不改变。通过只允许进入实时集成与输出契约审计；所有任务已消费，不形成发布结论。
