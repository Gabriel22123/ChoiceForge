# 研究主线：把“校准决策”拆成可验证的问题

项目希望让一个小模型读懂任务、材料与临时提供的候选项，对新任务给出可用的判断与概率。质量门禁只是例子。开源的价值应是：**原理讲清楚，实验能重做，结论能被检查，模型能继续训练。**

我们研究公开可描述的校准决策目标，并采用独立实现，不声称还原任何私有训练方案。

当前已把这套拆分接到真实 2B decoder：从同一初始化比较硬目标、完整教师分布、
有序 RPS，以及使用独立留一基线的高斯策略梯度。13 个案例、一个种子、8 次更新只够
验证实现和观察方向，不足以选择方法。正式证据必须覆盖四个整工作流留出折和
42/43/44 三个种子。

## 一、将一个大主张拆成四层

```mermaid
flowchart LR
    A[评分是否鼓励诚实概率] --> B[实际更新是否保留该目标]
    B --> C[训练与推理是否报告同一种概率]
    C --> D[新任务上是否仍然可靠]
```

每一步都需要独立证据，上一步成立不能直接推出下一步。

| 层次 | 实际问题 | 如何检验 |
|---|---|---|
| 决策接口 | 能否给临时候选评分，固定返回结构？ | 不同候选数、改 ID、合法 JSON、重载一致性 |
| 表示与泛化 | 是否理解新任务、新候选含义？ | 按整个任务留出，而不只随机留出同类样本 |
| 概率目标 | 选对之外，报出的信心是否有用？ | 准确率、NLL、Brier、ECE、风险与覆盖率一起看 |
| 优化方法 | 怎样让参数更有效地学到该目标？ | 固定目标和采样条件，再比较不同梯度估计方法 |

固定 JSON 解决输出格式；它不保证判断正确。动态候选接口解决标签空间限制；它不保证通用能力。可微的概率评分允许直接反向传播；它不证明所有奖励都不需要强化学习。

## 二、为什么概率评分是关键，而不只是奖励“答对”

设某类可用信息下，真实答案的分布是 `p`，模型报告 `q`。如果只奖励最大概率候选选对，模型报 0.60 或 0.99 可能得到同样的分数，无法约束其信心。

我们先研究已有的严格适当评分规则：

```text
L(q,y) = -log(q_y) + β Σk (q_k - 1[k=y])²

E[L(q,Y)] - E[L(p,Y)] = KL(p || q) + β ||p-q||²
```

当 `β ≥ 0`，总体期望下诚实报告 `q=p` 最优。这是已知性质，不能当作我们的算法发明；可参考 [Gneiting 与 Raftery 的原始论文](https://sites.stat.washington.edu/people/raftery/Research/PDF/Gneiting2007jasa.pdf)。

这个等式也**不意味着训练完就校准**。有限数据、标签噪声、模型表达能力、优化误差、任务分布变化，都可能使实际模型偏离该最优点。尤其不能由训练集概率可靠，推断新任务概率也可靠。

这里的 `p` 是给定可用信息时的结果分布。这个目标本身没有显式建立“模型对自己缺乏知识有多不确定”的机制，因此不能把适当评分规则直接等同于解决了认知不确定性。

“信息不足”是任务定义的一种答案；“模型没有把握”是模型能力的不确定性，二者应分开。我们不会把所有低概率判断自动标成“信息不足”。

## 三、把“强化学习”与“想优化的目标”分开

为了单独研究梯度估计，设模型输出分数 `μ`，采样 `z=μ+σε`，优化：

```text
J(μ) = Eε[L(softmax(μ+σε), y)]
```

对同一个 `J`，可以比较：

1. **策略梯度**：由采样分数的概率密度估计梯度，不需要对奖励本身求导。
2. **重参数化梯度**：固定这次采到的 `ε`，通过可微的 `L` 直接反向传播。

我们的留一基线只使用同组其他样本的损失，不包含当前样本；两种估计器使用相同噪声。此处不做组内奖励标准差归一化，因为随机的归一化分母会改变估计器性质，不能再不加说明地当作原期望目标的无偏梯度。

这是为了隔离变量而固定的独立训练协议。实验结论只对本项目明确定义的比较成立。

我们还构造了一个驻点检查：先解出带噪二分类交叉熵的总体最优点，再检查不同更新方法的平均梯度。真实概率 0.9、每个 logit 噪声标准差 0.4、每组 16 次采样时，留一基线策略梯度与直接求导都接近零；组内再除以损失标准差后，平均梯度约为 -1.289，反而会继续提高第一个类别的信心。

这说明“奖励使用适当评分规则”与“实际更新保留它的最优点”是两件事。这里只针对明确定义的组标准化更新构造反例，不包含裁剪、辅助 CE 等机制，也不据此推断任何外部实现。复现实验见 `scripts/normalization_study.py`。

对于已知、可微的概率评分，直接求导是值得检验的简单基线。对于不可微评分、外部交互、延迟反馈等问题，策略梯度仍有适用价值。是否采用强化学习，应由奖励和反馈结构决定。

## 四、加噪训练与去噪推理，未必对应同一个概率

再看一个可直接求解的小问题：二分类事件真实发生概率是 `p`，两个 logits 分别加入独立高斯噪声，仅使用交叉熵训练。总体最优条件是：

```text
Eε[sigmoid(d + ε1 - ε2)] = p
```

它约束的是**扰动后的平均概率**，并不直接要求去掉噪声后的 `sigmoid(d)=p`。

例如，当 `p=0.9`、每个 logit 的噪声标准差为 1 时，数值求解得到：扰动后平均概率为 0.9000，但无噪声推理概率约为 0.9468。模型可能已经把训练目标优化到最优，推理仍显得过度自信。

这是我们独立构造的反例：**讨论校准时，必须明确奖励作用于什么随机变量，以及上线究竟报告哪一种概率。** 实验使用两个精度的高斯求积交叉验证，见 `scripts/noise_optimum_study.py`。

## 五、第一轮模型实验为什么这样设计

固定公开 EuroBERT-2.1B、初始化、数据、步数与每批两个换序视图，比较：

- A：交叉熵。
- B：交叉熵 + Brier。
- C：交叉熵 + Brier + 换序一致性。

**B 对 A**检验额外概率目标；**C 对 B**检验一致性惩罚。A、B 同样各看两个换序视图，避免把额外数据增强或额外计算误认为一致性目标的贡献。

每组再分别报告原始概率与只用验证集拟合温度后的概率。若收益能被简单的温度缩放追平，就应如实报告。换序检查同时看“答案始终一致”和“每次都对”，防止模型稳定地选错。

两份训练视图仍各自启用 dropout，所以一致性项同时约束换序与随机屏蔽造成的变化。本轮只研究该训练目标的增量效果，没有分离这两个来源，也没有完成 encoder 与 decoder 或不同参数规模的对照。

实验协议、源文件、初始化参数、样本 ID 与逐批换序计划都有记录。详见 [英文实验协议](RESEARCH.md)。这是本地冻结，未做外部预注册。

## 六、怎样才算值得开源的研究成果

第一阶段交付完整、诚实的研究基线，不急着宣称超过已有模型：

- **可解释**：目标、梯度、噪声、推理概率分别是什么。
- **可复现**：公开许可的数据、固定版本、数据转换、训练配置与原始结果。
- **可检验**：公平对照、负结果、任务迁移与失败样例，不只展示几个成功调用。
- **可扩展**：统一数据接口，允许用户组织自己的任务并继续训练。

后续有希望形成独立贡献的方向，应由结果决定：更稳定的候选表示、在迁移任务上有用的置信度、同等资源下更有效的训练。它们目前是研究问题，不是已经实现的优势。

在声称优于基线前，还需要多随机种子、更大规模、未用于开发的任务集合，以及同等条件的架构和训练算法对照。当前一轮小样本结果不能证明“一切场景零样本”。

## 七、从数值实验接到真实模型后的发现

随后完成了三组真实 LoRA 续训，见[模型梯度对照](GRADIENT_TRAINING_STUDY.zh-CN.md)。
相同带噪目标下，直接求导与策略梯度的表现因任务而异。策略梯度本轮保住了更多
SNLI 和代码策略的正确判断，意图稍有退步；新增 SNLI 准确率仍未超过起点。

另外，三组全部更新都触发了范数裁剪，验证集温度也未可靠迁移到情绪任务。这把
理论问题落到了实际工程：奖励公式、原始梯度、优化器更新和推理概率必须分别核对。
不宜用其中某一环成立，替代最终可靠性的验证。补充的[概率平均观察](NOISY_INFERENCE.zh-CN.md)
同样没有给出跨任务统一改善。
