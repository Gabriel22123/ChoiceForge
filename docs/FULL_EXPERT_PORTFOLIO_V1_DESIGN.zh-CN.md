# 全来源专家组合 V1 设计

决策稳定专家组合的 27 折留一来源验证通过后，使用完全相同的目标、惩罚、投影步长和三个随机种子，在九个已消费训练来源上重新估计全来源组合权重。

本阶段不读取 SciFact。输出只有七条路径（父模型和六专家）的非负凸组合权重、权重哈希以及已消费验证集的机械复核结果。三个种子的权重文件、训练配置和代码哈希必须先提交；只有三套组合都满足权重单纯形、准确率严格不变、已消费 proper-loss 收益至少 0.01、上下文优势不退化，才允许冻结并执行 SciFact 最终协议。

权重组合不是新的语言模型参数更新。它是可审计的小型策略层，推理时仍使用决策不翻转投影，并沿用严格 JSON、概率和人工复核输出契约。
