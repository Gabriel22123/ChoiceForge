# ChoiceForge 本地阶段完成结论

## 已完成

- 只使用可追溯的公开数据训练和评测。
- 支持动态任务、上下文和 2–32 个候选项。
- 输出由程序构造并严格校验，只含选择、概率、复核标记、分数语义和校准状态。
- RLCD 风格的结果反馈、proper loss、上下文对照和多任务冲突都有可复现实验与保留的负结果。
- encoder 与 decoder 路线完成多种子对比，最终选择公开 MiniCPM 2B decoder。
- 决策稳定专家组合在已消费的九个来源上通过 27 折留一来源验证。
- 三个冻结种子在未见 SciFact 任务族上都保持全部硬选择，并稳定改善交叉熵、Brier、proper loss 和上下文利用。
- 六专家组合已精确合并为一个约 14 MB 的适配器，并在 5,765 行上验证等价。
- 适配器与父决策参数已组装为约 55 MB 的本地模型包，并通过真实命令行推理。
- Git 历史、发布清单、模型卡、许可证、发布审查材料和可加载参数包齐备。

## 当前边界

项目达到了“本地可公开审查候选”的目标。它没有证明所有任务都能零样本提升；SciFact 只提供一个新任务族的独立证据。硬准确率被设计为保持不变，提升体现在概率质量与上下文利用。所有输出仍要求人工复核。

文档、内部链接、凭证或本地绝对路径。
