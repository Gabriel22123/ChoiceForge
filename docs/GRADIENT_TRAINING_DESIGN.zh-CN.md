# 将校准决策的梯度逻辑接到真实模型

本轮将前面的数值实验接入 EuroBERT + LoRA 训练。研究的是明确写出的公开目标与
更新方式，不声称复原任何私有训练配方，也不把策略梯度名称当作性能保证。

## 1. 三组各回答什么问题

| 组别 | 目标 | 计算梯度 |
|---|---|---|
| A-clean | 无噪声 CE + 0.5 Brier | 直接反向传播 |
| B-pathwise | 高斯扰动后的平均 CE + 0.5 Brier | 重参数化后直接反向传播 |
| C-score-function | 与 B 相同的带噪目标 | Gaussian policy 的策略梯度，留一成本基线 |

A 与 B 用来观察“加入噪声”的影响；B 与 C 才是同一目标下的梯度方法对比。
不能把 A 与 C 的任何差异全部归因于强化学习。

策略是作用于连续分数向量的高斯分布，不是对文本 token 做自回归生成，也不是
外部环境中的多步行动学习。基础编码器每个请求只运行一份训练视图，随后在输出
分数上采样 16 次；16 个样本不意味着运行 16 次大模型。

## 2. 目标和实际更新

设真实候选个数为 K，模型分数为 μ；先减去 K 个分数的均值，得到 m。
对每个请求独立采样 G=16 个 ε，设 σ=0.4：

```text
z_g = m + σ ε_g
L_g = -log softmax(z_g)[y] + 0.5 × Brier(softmax(z_g), y)
J = E[L_g]
```

B 直接通过 z 对 μ 求导。C 将采样动作 z 与成本 L 从反向图中分离，使用：

```text
b_g = 其他 G-1 个样本成本的平均值
surrogate = mean_g[(L_g - b_g) × log Normal(z_g; m, σ²I)]
```

我们最小化成本，因此这里是正的成本优势；写成奖励时相当于奖励 `-L`。
留一基线不包含当前动作的成本。没有再除以组内奖励标准差，没有 PPO 比率裁剪，
也没有额外的无噪声 CE 辅助项。它是明确选定的对照方法，不等于所有 RLCD 方法。

减去候选分数均值不改变 softmax 的数学概率，却去除了所有候选共同加一个常数的
无效参数方向。B、C 都采用这个处理。填充出来的伪候选不进入奖励或策略密度。

在这个目标和采样条件下，两种方法估计同一个梯度；这句话针对优化器之前的估计。
实际训练使用 AdamW 和全局梯度范数裁剪，更新已不再等于原始无偏估计。因此记录
每步裁剪前范数和裁剪次数，不能用理论无偏性直接声称训练轨迹或概率最优点有保证。

**C 的 surrogate 数值不是概率损失。** 日志分别保留真实采样成本与优化替代量；
否则负的 surrogate 容易被误读为“模型损失特别低”。

## 3. 本轮固定的条件

- 起点：上一轮独立评分权重；三组读取同一文件，分别建立新优化器。
- 数据：先前公开多任务数据与单独准备的 SNLI 合并，保留原来的来源、许可、划分。
  全量准备 30,640 条；**本轮仅取 192 条训练、96 条验证、192 条测试**。
  实际续训为四个训练来源各 48 条，其中新增 SNLI 48 条，另 144 条是起点训练中
  已见过的旧任务样本。这是受控的短程适配，不是全量语义训练。
- 预算：1 轮、24 次参数更新、同一批次与候选顺序计划，单随机种子。
- 模型：同一原始 EuroBERT-2.1B、全 32 层 rank-8 LoRA、共享候选评分头。
- B/C 使用相同独立 CPU 随机数生成器及噪声哈希。采样不消耗 dropout 的随机数流。
- 保存最终更新后的权重；测试数据不用于选轮次、温度、学习率或噪声强度。

先评测未经这轮更新的起点模型。其温度也只在本轮同一验证集上拟合，避免沿用
旧温度造成额外口径差异。再逐组训练、评测并做 25 条请求的换序检查。

哈希核对覆盖初始可训练参数、来源权重、数据 ID、候选顺序、编码工作量和 B/C
噪声计划。具体配置在每组 `model.json`；步骤记录在 `optimizer-steps.jsonl`。

## 4. 怎样读结果

1. 逐任务报告准确率与 NLL/Brier/ECE，包括原始概率、验证集温度缩放后的概率。
2. SNLI 在本轮有训练样本，是已训练任务的新样本，不能算任务零样本。
3. 情绪任务仍未进入微调或温度拟合，但已经是反复检查的开发诊断；不能叫新盲测。
4. 推理使用无噪声分数。训练平均概率与无噪声概率的差异仍需通过实测检查，
   不能因为训练采用概率评分就默认推理已校准。
5. 参数更新次数、编码输入相同；分数采样和梯度构建有不同的小额计算开销。
6. 单种子短程续训只检验本设置下的局部适配效果，不代表从零训练或收敛后的排名。

当前仍缺多随机种子、更充分训练、未用于开发的新任务盲测，以及 encoder/decoder
对照。这些限制不应被“已接入 RL”掩盖。

## 复现入口

```bash
python scripts/compose_public_data.py
python scripts/run_gradient_training_study.py --device mps
```

需要先准备前两份固定公开数据、原始底座及上一轮独立评分检查点。所有输出目录
要求不存在，避免覆盖以前的实验。代码支持显式选择 CUDA/CPU；本轮实机为 MPS。

单独继续训练自己的公开适配器，可以使用
`configs/eurobert-independent-pathwise-pilot.json` 或
`configs/eurobert-independent-score-function-pilot.json`，例如：

```bash
decision-model train --data data/public-multitask-v2/cases.jsonl \
  --config configs/eurobert-independent-score-function-pilot.json \
  --init-from runs/architecture-study-v1/D-independent \
  --base-path models/eurobert-2.1b --output runs/my-score-function-run
```

这是小规模研究配置，不是推荐的生产训练配方。`--init-from` 只加载适配器与头，
优化器重新创建；不是从中断点精确恢复。
