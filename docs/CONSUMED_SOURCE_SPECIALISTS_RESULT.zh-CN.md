# 既有公开任务族独立专家筛选结果

五个已消费公开任务族分别使用相同的冻结 2B 表示、父决策头、残差结构和三随机种子协议。
结果只用于机制判断，不构成新鲜发布证据。

| 任务族 | 平均效用 | 平均准确率差 | 平均 NLL 差 | 三种子结论 |
|---|---:|---:|---:|---|
| SNLI | +0.0711 | +0.0069 | -0.0447 | 通过 |
| PAWS-Wiki | +0.0627 | +0.0104 | -0.0467 | 通过 |
| CLINC | +0.0153 | +0.0000 | -0.0183 | 通过 |
| Typed Decisions | -0.0668 | -0.0437 | +0.0070 | 失败 |
| JSON Schema | -0.0968 | +0.0476 | +0.0750 | 失败 |

## 结论

“只有 QASC 一个正效用任务族”并不是其他任务不可学习，而是此前把同一个 QASC 专家应用
到了所有来源。为任务族分别训练专家后，SNLI、PAWS-Wiki 与 CLINC 均在三个种子下稳定
通过冻结效用、准确率和 NLL 门槛。加上已有 QASC，当前已有四个来源独立的已消费正效用
专家族，满足继续研究专家选择机制的最低数据多样性条件。

两个失败也提供了必要边界：

- Typed Decisions 的残差专家同时损害准确率和效用，说明固定表示下并非每种任务都能用
  相同小头可靠修复。
- JSON Schema 的准确率提高 4.76 个百分点，但 NLL 平均恶化 0.0750，平均效用为
  -0.0968。若只用准确率定义“专家更好”，路由会把大量过度自信错误引入线上；效用必须
  同时约束概率质量和上下文贡献。

## 下一步

先冻结并计算“专家 × 任务族”的完整交叉效用矩阵，验证正效用是否集中在对角线、哪些专家
会伤害其他任务，以及父模型是否应保留为默认路径。之后才能把路由问题从“是否打开一个
QASC 专家”改写为“在父模型与多个专家之间选择”，并重新做留一任务族验证。
