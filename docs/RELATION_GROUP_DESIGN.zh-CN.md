# 同前提成组采样：只改变更新内的样本组合

## 目标

上一轮预热组虽然推断总分更高，seed43 的“信息不足”仍是 0/64。
本轮从公开 SNLI 的原始训练部分构造同前提三类样本，检验成组更新能否改善
信息不足判断。训练目标继续固定为 CE+0.5 Brier，不新增或声称复刻专有 RLCD 算法。

## 数据

- 使用已锁定 SHA256 的官方 SNLI1.0 归档，保留原始文字与 gold_label。
- 排除官方 dev/test 出现过的所有标准化前提，包括无共识标签行；排除冲突标签和重复对。
- 每个训练前提、每类标签取最小内容哈希的一个样本，再按前提哈希选择 256 个完整组。
- 768 条推断样本三类各 256 条，与上一轮 768 条推断训练样本的 ID 交集为 0。
- 配上原来的 256 条旧任务训练样本；验证 192 条、测试 384 条保持原对象不变。
- 768 条中 704 条仅有一个上游标注，不能称为全部多人一致标注；不自行改标签。
- 精确标准化去重不能排除所有语义近重复，且测试已在开发中多次观察。
- 自写证据翻转诊断仍不进入训练。

SNLI 派生数据保留 CC BY-SA4.0，旧任务数据各自保留原许可。数据目录包含
逐行来源、原始索引、归档校验值、标注记录、归因说明和上游 README。

## 两个对照组

两组使用同一个 D-independent 起点、同一个 seed42、完全相同的 1,024 条训练样本。
每组固定两轮、256 次更新、2,048 次样本处理，最终终点评测，不选测试冠军。

| 每次更新 | grouped | dispersed |
|---|---|---|
| 推断样本 | 两个前提各一组三类样本 | 六个不同前提的样本 |
| 标签数量 | 支持、矛盾、信息不足各 2 条 | 相同 |
| 旧任务复习 | 2 条 | 相同 ID、相同位置 |
| 标签位置 | 固定随机排列 | 每个位置的标签与 grouped 一致 |

每轮打乱 256 个前提的顺序；dispersed 将三个标签的前提索引分别循环偏移
0、85、170，确保每次更新六个前提不同，但每个样本仍恰好出现一次。
微批为 2，累积 4 次再更新参数。模型每次仍只看单条样本，分组仅改变梯度聚合，
没有跨样本注意力、额外对比损失、组 ID 或标签进入模型文本。

其余沿用 32 层 rank8 LoRA、相同共享评分头、学习率、dropout0.05、梯度裁剪。
有效 token 和候选序列总量相同；不同批组合会造成 padding 工作量差异，不宣称 FLOPs 相等。

## 主要评价

1. 固定 64 条信息不足测试样本的召回率，并报告“判为信息不足时有多少答对”，
   防止一律回答信息不足得到虚假进步；同时检查支持与矛盾各 64 条。
2. SNLI 总准确率、原始 NLL/Brier、验证集温度校准后的概率质量。
3. 意图、Schema、代码策略和未参加微调的情绪任务是否退步。
4. 同一证据翻转诊断的单题与完整组通过率；候选换序稳定性。

本轮只有一个预先固定的种子；成组效果需要后续跨种子复核。
与旧实验相比，推断训练数据、训练轮数和每次更新的标签平衡都变了，所以历史差值不能只归因于分组。
SNLI 是训练任务，不是零样本证据。本轮全程本地，不发布 GitHub。
