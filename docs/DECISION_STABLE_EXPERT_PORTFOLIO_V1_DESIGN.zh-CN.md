# 决策稳定专家组合 V1 设计

## 动机

六专家安全 oracle 证明专家库有显著收益，但逐请求安全分类在留出任务族上只能达到 71.43% 安全精度，并把覆盖率压到 0.47%。共享残差探针又表明，直接把所有任务压进一个参数头会产生明显的任务梯度冲突。

本实验改为学习一个低维的专家组合。它把已训练专家视为可复用方向，只优化非负、和为一的全局权重；推理时再沿“父模型 → 专家组合”方向取不改变父模型最终选择的最大步长。这个投影不使用标签，并把同一个步长用于完整上下文和空上下文。

## 冻结协议

- 九个公开来源逐一作为外层留出来源；训练权重时完全排除该来源。
- 若留出来源存在同名专家，同时排除该专家，避免把同任务专家当作零样本能力。
- 权重通过 softmax 参数化，只能形成父模型与其余专家 logits 的凸组合。
- 训练目标按来源等权，而非按样本数加权；proper-loss 与上下文优势若在任一训练来源上退化，分别施加固定系数 10 的平方惩罚。
- 三个种子为 42、43、44；每个种子 600 次 Adam 更新，学习率 0.03。
- 推理步长固定为 0.125、0.25、0.5、0.75、1.0，选择仍保持父模型 argmax 的最大步长；同一步长应用到空上下文分支。
- 组合与投影只读取候选 logits，不读取来源名、样本 ID 或标签；候选重排必须严格等变。

## 冻结门槛

- 27 个外层来源/种子组合完整，且训练数据和同名专家均无外层泄漏。
- 每个来源、每个种子的准确率差必须严格为零。
- 九来源宏平均交叉熵和 Brier 均不得变差，宏平均 proper-loss 收益至少 0.01，上下文优势差至少为零。
- 任一来源宏平均交叉熵增加不得超过 0.02，proper-loss 收益不得低于 -0.02，上下文优势差不得低于 -0.05。
- 宏平均推理步长至少 0.05，防止退化为恒等父模型。

这些来源都已消费，门槛通过只允许训练全来源组合并冻结最终评测协议，不能直接宣称零样本发布成功。SciFact 在最终组合及其哈希冻结前继续保持封存。
